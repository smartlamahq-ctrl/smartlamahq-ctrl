## 🚀 What we're building

### 🌤️ Pond Weather

A weather web app designed to make local forecasts easy to find and understand, whether you're checking a familiar place or somewhere new.

- **Installable Progressive Web App (PWA)**
- English and Hebrew interfaces, including right-to-left support
- Location search, saved places, and Home location features
- Accessibility, privacy-conscious behavior, and integrity-verified updates
